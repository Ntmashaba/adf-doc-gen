Where Power BI data comes from

Each Power BI source (from pbi-doc-gen) matched to the Data Factory pipelines that write it (from adf-doc-gen). Exact: same server, database and object. Possible: the names match but the location is not proven, or the pipeline's target is resolved at runtime or hidden in code. Read only: factories read it but none writes it. No match: nothing in the supplied factories touches it. Views and procedures are matched by their own name only; this page does not claim the tables underneath them.
